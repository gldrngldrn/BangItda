무엇을 하는 앱인가

공공임대·청년주택 모집공고는 LH, SH(서울주택도시공사), GH(경기주택도시공사), 각 지방개발공사가 저마다 다른 게시판에 올립니다. 마감을 놓치는 가장 흔한 이유는 공고가 없어서가 아니라 어디에 올라왔는지 모르기 때문입니다.

방잇다는 이 공고들을 한곳에 모읍니다.

  • 공고 수집 — 공공데이터포털 오픈API와 각 기관의 공개 게시판에서 모집공고를 주기적으로 모아 하나의 목록으로 정리합니다.
  • 요약 — 첨부된 공고문 PDF에서 접수 기간과 신청 자격을 뽑아 한눈에 볼 수 있게 정리합니다.
  • 마감 알림 — 새 공고가 올라오거나 마감이 다가오면 알려줍니다.
  • 구글 캘린더 연동 — 관심 지역의 공고 접수 기간을 사용자의 구글 캘린더에 일정으로 등록합니다.

구글 캘린더 연동에 대하여

캘린더 연동은 선택 기능입니다. 쓰지 않아도 나머지 기능은 그대로 동작하고, 구글 계정을 연결하지 않으면 어떤 권한도 요청하지 않습니다.

연결하면 방잇다가 이런 일을 합니다.

  • 사용자의 캘린더에 방잇다 공고 – 서울 처럼 지역별 캘린더를 새로 만듭니다.
  • 그 캘린더 안에 공고 하나당 일정 하나를 만듭니다. 일정 기간은 공고의 접수 시작일~마감일이고, 설명에는 공고 제목·기관·원문 링크가 들어갑니다.
  • 공고가 갱신되면 해당 일정을 갱신하고, 마감된 공고의 일정은 정리합니다.

요청하는 권한은 .../auth/calendar.app.created 하나뿐입니다. 이 권한은 이 앱이 직접 만든 캘린더에만 접근할 수 있습니다. 사용자가 원래 쓰던 캘린더의 일정은 읽지도, 고치지도, 지우지도 못합니다 — 권한 자체가 없습니다.

연동을 그만두려면 캘린더 목록에서 방잇다 공고 캘린더를 지우거나, 구글 계정 권한 페이지에서 앱 연결을 해제하면 됩니다.

데이터 출처

수집 대상은 모두 공개된 모집공고입니다. 공공데이터포털 오픈API와 각 기관이 웹에 게시한 공고 게시판을 이용하며, 로그인이 필요한 자료나 개인이 신청한 내역 같은 것은 다루지 않습니다.

정리된 공고 데이터는 누구나 볼 수 있게 공개 저장소에 올려둡니다.

참고용입니다. 방잇다는 각 기관의 공고를 모아 보여줄 뿐이며, 신청 자격·일정·당첨 여부에 대한 판단은 하지 않습니다. 실제 신청 전에는 반드시 해당 기관의 공고 원문을 확인하세요. 자동 수집 과정에서 내용이 누락되거나 잘못 읽힐 수 있습니다.
